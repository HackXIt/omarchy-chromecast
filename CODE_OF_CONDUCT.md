# Code of Conduct

This project is intended to be a welcoming and practical place to collaborate.

## Expected behavior

- Be respectful and constructive.
- Assume good intent, but accept corrections gracefully.
- Keep discussions focused on the project and the user problem being solved.
- Critique ideas and code, not people.

## Unacceptable behavior

- Harassment, threats, or personal attacks.
- Discriminatory or demeaning language.
- Publishing private information without permission.
- Sustained off-topic disruption.

## Enforcement

Maintainers may edit, hide, lock, or remove comments and may block users when needed to keep the project healthy. If you see a problem, report it to the maintainer with links or screenshots where possible.
