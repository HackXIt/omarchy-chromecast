# Security Policy

## Supported versions

Security fixes are handled on the `main` branch. This project does not currently maintain multiple release branches.

## Reporting a vulnerability

Please do **not** report security issues in a public GitHub issue.

Use GitHub's private vulnerability reporting flow for this repository if it is available. If it is not available, contact the maintainer privately first and include enough detail to reproduce the issue safely.

Helpful details include:

- affected command or plugin flow
- local environment details
- reproduction steps
- expected impact
- whether the issue affects the isolated Chromium profile, DevTools binding, shell command execution, or filesystem paths

The maintainer will acknowledge valid reports as time allows and coordinate a fix before public disclosure.
