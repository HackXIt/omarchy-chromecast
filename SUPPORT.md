# Support

Omarchy Chromecast is maintained as an open-source project without guaranteed support.

## Where to ask

- Use GitHub Issues for reproducible bugs and actionable feature requests.
- Use GitHub Discussions for questions, ideas, and troubleshooting that is not yet a confirmed bug.

## Before opening an issue

Please run:

```bash
chromium-castctl doctor --quickshell
chromium-castctl status
chromium-castctl sinks
```

Include relevant output, your Omarchy/Quickshell context, and whether Chromium's built-in Cast menu can see the target.
